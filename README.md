# The Most Honest Outage Line

One honest status page line, written by a pure-stdlib Python program for the make.fun bounty **The Most Honest Outage Line**.

> Every server is down and I can't reach our monitoring, so I don't know what failed or when we'll be back — I'll update here the moment I can check anything.

Run `python3 main.py` — it writes the line (one line, 156 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–160 characters, single line, not only white space, no trailing newline).
